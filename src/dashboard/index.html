Switchyard help
Getting Started

1. Run the server at login: node src/index.ts install-service (or node src/index.ts in a terminal).

2. Optional, for Claude Code agents: node src/index.ts install, then run claude in any terminal.

3. Open the Switchyard menu bar app and press Sort. Each project's windows go to its own desktop.

Contexts

Cards: one per project. Switch shows its desktop, Park saves and closes its windows, Restore brings them back, Tidy lays them out.

Desktop select: picks which desktop and ⌥ key a project uses. Picking a taken one swaps the two.

Sort: carries every window to its project's desktop. Unsorted windows go to the shared (last) desktop.

Desktops: every desktop with its owner. Go shows it; Close removes an empty one. Tick several to close them at once.

Layouts: arrange a desktop by hand, press Save layout, and Tidy puts windows back there.

Panels

Agents — Click an agent to filter timeline and send instructions. Shows live tool activity, diff stats (+/-), files touched, and session duration.

Missions — One per project an agent starts work in. Open a mission to mark it done, reopen it, or delete it.

Usage — Real API costs from Claude Code logs. Switch periods (24H/7D/30D/All). Shows token breakdown, cost by model, context window health for active sessions, and cache hit rate.

Timeline — Click any event row to expand full tool input/output. Select an agent to show only its events.

Alerts

STUCK — No activity for 2+ min. Check the agent's terminal.

LOOP — Repeating the same tool calls. Agent may need redirection.

SPIRAL — Editing the same file repeatedly. Send a clarifying instruction.

ERRORS — 5+ failures. Review the timeline for error details.

MARATHON — Running 30+ min. Consider compacting context.

Enable browser notifications to get alerts even when this tab is in the background.

Agent Actions

• Hover an agent to see quick-action buttons: Copy Path (working directory) and Copy ID (session ID).

• Click an agent to select it, filter the timeline, and enable the instruction input.

• Use the copied path to find the right terminal window (e.g. Cmd+Tab and match the folder name).

Mission Actions

• Click a mission to expand it and see action buttons.

• Open: Done marks it complete; Delete removes it.

• Done: Reopen puts it back on the list.

Tips

• Set SWITCHYARD_COST_PER_TOOL_CALL=0.01 to adjust estimated costs when JSONL logs aren't available.

• Data persists in ~/.switchyard/data.db — survives restarts.

• Real costs are read from ~/.claude/projects/ JSONL session logs.

• The secret scanner checks every tool output for leaked API keys, tokens, and private keys.
